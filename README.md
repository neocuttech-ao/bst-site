# si-csuite-site

Публичный репозиторий: только сайт. Отдаётся в интернет через GitHub Pages
из ветки `main`, корень репозитория.

Коммерческих данных, финансов, лидов и клиентской информации здесь быть
не должно — они живут в приватном репозитории `si-csuite-consulting`.

- `index.html` — пока заглушка на словенском, `noindex`
- `.nojekyll` — отключает обработку Jekyll
- `CNAME` — появится, когда подключим свой домен
